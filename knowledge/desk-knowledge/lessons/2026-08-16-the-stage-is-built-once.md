# The stage is built once — "bespoke scenes" is not enough if the frame is unproduced

**Purpose:** this file exists to explain why a video full of hand-authored scenes can still be
rejected as *plain*, and what the fix actually is.
**When to read:** read this before authoring any HyperFrames scene, and any time an owner note says
a video looked flat, cheap or like a slideshow.
**Do not duplicate:** if writing about the scene substrate, `_lib/hf-fx.*`, stage layers or the
`FX.*` helpers, extend this file instead of creating a new one.

## Finding

021 shipped **24 bespoke scenes**, every one authored fresh against the strategist standard, and the
owner's verdict was still *"previše plain — slideshow sa rečima i običnom pozadinom"*.

The scenes were not the problem. **The frame was.** Each scene file re-invented a thin stage in its
own CSS — one radial gradient, one grid, one glow — and then spent its entire budget on typography
and timing. Nothing in the picture ever had depth, grain, light falloff, weight, or life that
continued between beats. A perfectly staged idea rendered on an unproduced frame still reads as text
on a background.

So "author every scene bespoke" is a necessary rule, not a sufficient one. The sufficient version is:
**the stage is production value, it is the same in every scene, and therefore it is built once.**

## What to do

Include `_lib/hf-fx.css` + `_lib/hf-fx.js` and call `FX.init(S, {...})` + `FX.ambient(tl)`. That
gives the scene a six-layer stage (depth ground, masked blueprint grid, volumetric light shafts, a
re-aimable focal bloom, deterministic dust, stepped film grain, vignette, caption band), a camera
rig, physical paper with real shadow stacks, and continuous motivated secondary motion — before the
author has staged anything. The scene file then contains **art direction only**.

Two rules that came out of building it:

1. **Pick the video's spine object before writing scene one.** 022's is THE PILE — the same stack of
   pages lands, is read, is wiped, grows, is re-bought, loses its bottom page and is finally
   compressed into five lines, across eleven scenes. Continuity of one object is the thing a deck of
   swapped cards can never buy, and it costs nothing once the object is in the substrate.
2. **`FX.fromTo`, never `gsap.fromTo`, for any beat later than 0.** `fromTo` defaults to
   `immediateRender: true`, so a tween placed at 12s applies its `from` values at *build* time: a
   gold page meant to appear late sat at opacity 0.2 from frame 0 and dirtied every earlier frame.
   The tempting global fix — `gsap.defaults({immediateRender:false})` — is **wrong** and was
   reverted: `gsap.set()` is a zero-duration tween that relies on immediateRender, so the default
   silently erases every opening state in the scene.
