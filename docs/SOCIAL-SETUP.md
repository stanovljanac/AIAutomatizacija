## How to create each account ("do I need a page / a review?")

| Platform | How to create it | Brand name now? | Approval needed to use? |
|---|---|---|---|
| **Facebook** | You **can't** rebrand a personal profile. Create a **Page** named "The Automation Desk" (free, attached to your personal account). The Page is your promo presence. | Yes — on the Page. | **No.** A Page is usable immediately. "Review/approval" only comes up later for *monetization* or some *API* features — never to post. |
| **Instagram** | Create a normal account with the brand @handle, then **Settings → Account type and tools → Switch to professional → Business** (or Creator). No separate page to make. | Yes — directly. | **No.** (Business account + a linked FB Page is required *later* for Postiz/API auto-posting, not for manual posting.) |
| **X (Twitter)** | Just sign up; set display name + @handle to the brand. | Yes — directly. | **No** for manual posting. API auto-posting needs a developer app (free tier is limited) — verify when we wire Postiz. |
| **Pinterest** | Create a **Business** account (free) — better analytics + the Pins API. Can also convert a personal one. | Yes — directly. | **No.** |
| **TikTok** | Sign up with the brand name/@handle; switch to **Business** account (free) for analytics. | Yes — directly. | **No** for manual posting. Auto-posting via TikTok's Content Posting API needs an **app audit** — that's the only real "review", and only for automation. |
| **Medium** | Create a personal account, then create a **Publication** named "The Automation Desk" for branded articles. | Yes — the publication. | **No.** Medium's API is limited, so it stays **semi-manual** (per NEXT-SESSION). |

### Rule of thumb
- **Facebook is the only platform that forces a separate Page** — you cannot use a renamed
  personal profile as the brand. Everywhere else the brand name/@handle goes straight on
  the account.
- The "review/approval" you were worried about is for **automation or monetization
  features**, *not* for basic manual posting. You can post the day you create the account.
- For the future auto-posting machine (Postiz): IG needs **Business + linked FB Page**, X
  needs a **dev app**, TikTok needs an **app audit**. We'll handle those in Phase B.

## Platform deep-dives: Pinterest & Medium

These two work differently enough from the social feeds to need their own how-to.

### Pinterest (a visual search engine, not a feed)

1. **Account:** create a **Business** account (free) — gives analytics + the Pins API for
   later auto-pinning via Postiz. (Or convert a personal account.)
2. **Boards:** create topical Boards, not a single dump — start with **"AI Automation Ideas"**
   and **"Office & Spreadsheet Automation"** (add more per cluster: email, scheduling…).
   Boards are how Pinterest reads your topical authority, mirroring the YouTube clusters
   (CHANNEL §3).
3. **Pins (per video):**
   - The **Short** → a **video Pin**.
   - The **vertical 1000×1500 thumbnail** → a **static image Pin**.
   - **Set the destination link to the YouTube URL** on every Pin — that's the whole point:
     Pinterest is a traffic source back to the video.
4. **Optional:** in **Settings → Claim**, claim your YouTube channel / website for attribution
   and richer Pins.
5. **Mental model:** Pins live on **Boards** (evergreen, searchable), *not* a chronological
   profile feed — a good Pin keeps pulling traffic for months. Pin the same video to more than
   one relevant Board.

### Medium (branded long-form, semi-manual)

1. **Account:** create a personal Medium account.
2. **Publication:** create a **Publication** named **"The Automation Desk"**; paste the
   **Long bio** (above) as its description, logo as the avatar. Articles go *under* the
   publication so they carry the brand.
3. **Per-video article:** an SEO write-up derived from the script via the future
   **`blog-from-transcript`** step (D-027). It's **semi-manual** — the Medium API is retired,
   so the flow is generate → **paste** into a new story under the publication → set the
   canonical/link back to the YouTube video.
4. Keep it original (our own structure/words, never a transcript dump — STYLE_GUIDE §4) and
   link the YouTube video prominently.
